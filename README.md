# Chasing Hearts
A Unity game inspired by American McGee's Alice: Madness Returns and other Alice in Wonderland media

## Engine
Unity 6000.3.10f1

## Controls
WASD - Move (left/right only)
Space - Jump

## Features
• Player movement (3D)
• Life tracking
• Checkpoints
• Levels
• Interaction System
